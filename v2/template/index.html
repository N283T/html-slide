Process

手順は矢印でつなぐ

  1. 測る現状のボトルネックを数値で押さえる
  2. 絞る効き目の大きい1点だけを選ぶ
  3. 試す小さく作って、同じ指標で比べる
  4. 広げる効いたら全体へ。効かなければ戻す
一度に変えるのは1つだけ。

Code

コードはそのまま貼る

def score(pred, truth, k=10):
    """Top-k accuracy over a batch."""
    hits = 0
    for p, t in zip(pred, truth):
        if t in p[:k]:
            hits += 1
    return hits / len(truth)  # 0.0 – 1.0

class="lang-py" を付けるだけで色が付きます。

着色は CSS Highlight API。DOM を書き換えないので、エディタで文字を直しても壊れません。

Review loop

コメントは、問題のある場所に置く

<section class="slide">
  <h2>結果</h2>
  <!-- @fix: 凡例が図に被っている。右上へ -->
  <hs-chart type="line">…</hs-chart>
</section>
  1. エディタで C を押して要素をクリック
  2. hs check がはみ出しと未解決コメントを一覧
  3. Claude が直して、コメントを消す
  4. 開いているブラウザはその1枚だけ差し替わる
